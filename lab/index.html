          Quand vaut-il mieux exercer avant l'échéance ?

            Voir les valeurs

            Hypothèses. Le prix de l'action suit un modèle aléatoire classique (mouvement brownien géométrique), avec un taux r, un dividende q et une volatilité sigma constants. Option européenne : exercice à l'échéance seulement. Option américaine : exercice possible à chaque nœud de l'arbre.

            Méthodes. Black-Scholes (formule exacte) ; arbre binomial à N pas ; Monte Carlo avec variable de contrôle (le prix de l'action à l'échéance, dont on connaît la moyenne) ; seuil d'exercice lu dans l'arbre à 400 pas.

            Limites. La volatilité est supposée constante, alors que celle du marché varie. Monte Carlo calcule seulement le prix de l'option européenne.
